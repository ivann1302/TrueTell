## Автоматизация и SEO

[Штатный hook Astro `astro:build:done`](https://docs.astro.build/en/reference/integrations-reference/#astrobuilddone) формирует XML после появления всех страниц: только published, без noindex, редиректов и чужого canonical. XML содержит HTTPS и единый завершающий `/`, уникален, экранируется и разбирается XML-парсером. `lastmod` берётся из записанной даты обновления статьи, никогда из времени сборки. Исторические даты перенесены без выдуманных исправлений; даты остальных страниц неизвестны и не добавлялись. Robots ссылается на текущий `/sitemap.xml`; правила обхода сохранены. Не добавлены фиктивные рейтинги/даты/отзывы или новый FAQ ради сниппетов.

Генератор проверяет фактические маршруты и ссылки на HTML/файлы, единственный H1, title/description и canonical. Тесты дополнительно проверяют уникальность метаданных, Open Graph, связь schema с каталогом, сохранение старых адресов, совпадение даты XML с HTML и обратные ссылки продуктов. Обработка robots/googlebot/yandex/noindex/none согласована с финальным валидатором. Неиндексируемая страница допускается только вне sitemap; canonical alias исключается и проверяется отдельно.

Изолированная smoke-сборка с четырьмя тестовыми записями подтвердила: published knowledge и blog появляются в своих каталогах, блоке продукта и XML без изменения списков; draft и noindex не попадают в эти блоки; `updatedAt` доходит до XML. Тестовые страницы находятся только в `/private/tmp`, рабочий сайт их не содержит. Публикация записи без страницы и битые ссылки вызывают ошибку. GSC, Яндекс Вебмастер и фактическая индексация не проверялись. [Google отдельно указывает](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), что sitemap служит подсказкой для обхода, а `lastmod` должен отражать достоверное изменение содержания.

## Проверки и ограничения

- `npm run lint`: без ошибок; три существующих предупреждения React Hooks в нетронутых chart-section и slider-section.
- `npm run build`: проходит; 29 канонических URL, внутренний реестр генерируется автоматически.
- `node --test scripts/*.test.mjs`: 65 тестов проходят; добавлены проверки каталогов, статусов, генерации XML и согласованности HTML/schema.
- `node scripts/indexnow.mjs --check`: локальная проверка XML, маршрутов, robots, canonical, SEO-файлов и ключа; отправка URL не выполнялась.
- `scripts/seo-browser.mjs`: Chrome, 320/390/768/1440 px, восемь затронутых каталогов/страниц, проверка H1, мобильного выравнивания, переполнения, фокуса клавиатуры, отсутствия новых Astro islands и ошибок скриптов. Внешние запросы заблокированы; это не измерение production Core Web Vitals.

Шесть существовавших статей имеют по одному `ArticleFigure`; статья об удалённых лидах уже имела два в незакоммиченных изменениях автора. Для этих шести материалов нужен отдельный редакционный этап с второй полезной иллюстрацией. Новые изображения и статьи не создавались по условию текущей задачи. Правило двух разных полезных изображений сохранено в [content-publishing.md](content-publishing.md).

Защищённые `.agents` доступны только для чтения и сохранены без изменений этой задачи. Новая классификация зафиксирована в `AGENTS.md` и документации; она имеет приоритет над старым указанием article skill всегда использовать пункт «Блог».
