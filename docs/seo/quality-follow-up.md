## Страница ошибки

Проверка опубликованного сайта подтвердила:

- `/404.html`: HTTP 200, `robots="index, follow"`, canonical отсутствует.
- `/seo-check-nonexistent-20261008/`: HTTP 404.

В локальную страницу ошибки добавлен `robots="noindex, follow"`. Это намеренное изменение прежней политики: прямой адрес статического файла не должен индексироваться при ответе 200. Валидатор IndexNow и регрессионные тесты теперь требуют noindex. Страница остаётся без canonical и вне sitemap; серверные правила `ErrorDocument` не изменялись. После деплоя нужно повторно проверить оба HTTP-статуса и наличие noindex в опубликованном HTML.

Успешная обработка карты не гарантирует индексацию всех URL.

## Core Web Vitals

Запрос для мобильных устройств к GSC Wizard вернул `notConfigured=true`: ключ CrUX API отсутствует. LCP, INP и CLS реальных пользователей не получены; оценка качества CWV не выставлялась. Это отсутствие настройки инструмента, а не подтверждение отсутствия данных у сайта или плохой скорости.

Следующее действие — настроить ключ Chrome UX Report API в разделе Core Web Vitals / API Key приложения либо проверить полевые данные в интерфейсе PageSpeed Insights или GSC. [PageSpeed Insights использует CrUX за предыдущие 28 дней](https://developers.google.com/speed/docs/insights/v5/about); при недостатке данных страницы может показать данные всего origin, а при недостатке данных origin — не показать полевых метрик. В отчёте фиксировать период, устройство, уровень URL/origin и p75. Лабораторные результаты Lighthouse не подменяют реальные CWV.
