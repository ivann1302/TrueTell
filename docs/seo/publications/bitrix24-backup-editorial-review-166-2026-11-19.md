# Резервная копия Битрикс24. Обновление №166 от 19.11.2026

SEO-090, UPDATE, База знаний, `/rezervnaya-kopiya-bitrix24/`. Статья помогает подготовить сохранение данных перед очисткой и выбрать способ возврата. Соседние инструкции описывают настройку экспорта, операции очистки и точечное восстановление конкретной сделки. Из статьи о выгрузке есть входящий переход.

## Проверенные факты

- Облачные копии создаются ежедневно и хранятся семь дней. Администратор обращается в поддержку, доступность зависит от тарифа. При полном откате теряются изменения после точки восстановления. [Восстановление данных](https://helpdesk.bitrix24.ru/open/24955644/).
- Для коробки на MySQL описан штатный мастер. Для PostgreSQL нужно согласовать процедуру базы и файлов с администратором. Новый подлинный снимок показывает список созданных архивов и меню одной копии. [Описание мастера](https://dev.1c-bitrix.ru/learning/course/index.php?COURSE_ID=48&LESSON_ID=5330), [требования к СУБД](https://helpdesk.bitrix24.ru/open/5825131/).
- В экспорт попадает список по фильтру. Товарная детализация может дать несколько строк на сделку. В учебном примере в плане три ID, в файле четыре строки и тоже три уникальных ID. Сверка состава выявляет пропуск 420 и лишний 598. Авторская схема использует вымышленные значения. Сохранён демонстрационный снимок экспорта из официальной справки. [Экспорт CRM](https://helpdesk.bitrix24.ru/open/20966844/).
- После удаления сначала проверяют корзину. Доступ зависит от тарифа, настроек типа и наличия записи. Восстановленной сделке присваивается новый ID. Проверка выполнена по документации. Реальные удаление, восстановление и проверка доступа на клиентском портале не проводились. [Корзина CRM](https://helpdesk.bitrix24.ru/open/24668648/).

## Редакционная проверка

Humanizer применён к заголовкам, введению, основному тексту, FAQ, подписям, CTA и метаданным. Из вводного блока убраны повторяющиеся определения. Проверка выгрузки показана на двух списках ID. Отдельно указан эффект облачного отката для новой сделки и для сделки со сменой стадии. Отпечаток записан в `humanizer-reviews.json`.

Независимый ревьюер сверил документацию, область применения штатного мастера, пример ID и три изображения. По замечаниям уточнены MySQL и PostgreSQL, видимая дата обновления и одинаковая чётность учебных ID.
