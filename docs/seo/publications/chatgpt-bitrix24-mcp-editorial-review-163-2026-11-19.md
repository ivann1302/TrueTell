SEO-075, UPDATE, База знаний, `/chatgpt-bitrix24-mcp/`. Сценарий статьи — подготовить чтение одной известной сделки в ChatGPT и сверить ответ с CRM. Общий обзор SEO-074 помогает выбрать способ подключения ИИ, SEO-086 разбирает выборку сделок. Ссылки из обновления ведут к разбору кодов полей, прав доступа и анализа списка сделок. Входящий переход — из каталога базы знаний.

## Факты

- В отчёте о проверке MCP TrueTell от 27 октября есть личный вход в Codex и успешное чтение сделки. Более поздние проверки в репозитории продукта охватывают Codex и MCP SDK. Подтверждения цепочки от входа до чтения в ChatGPT в доступных отчётах нет. Основания: `docs/MCP_LIVE_ACCEPTANCE_2026-10-27.md`, `docs/evidence/mcp-live-oauth-codex-smoke-2026-10-27.json`, `docs/MCP_ACCEPTANCE_BACKLOG.md` (ACC-16), `docs/CRM_CLEANUP_SCENARIOS_2026-11-06.md` в репозитории `bitrix_mcp`.
- Проверка доступности MCP в рабочем пространстве, вызова инструмента и фактического результата опирается на [руководство OpenAI по тестированию MCP в ChatGPT](https://developers.openai.com/plugins/deploy/connect-chatgpt).
- ID сделки, код стадии, воронка и ID ответственного сверены с контрактами чтения TrueTell и документацией Битрикс24. Код стадии сопоставляется со справочником выбранной воронки. [Чтение элемента по ID](https://apidocs.bitrix24.ru/api-reference/crm/universal/crm-item-get.html), [поля и стадии сделок](https://apidocs.bitrix24.ru/api-reference/crm/deals/).
- Обе инфографики используют учебные данные. Первая помогает выбрать одну из двух одноимённых сделок по ID. Вторая показывает совпавшие идентификаторы и расхождение в кодах стадии. CTA ведёт в форму TrueTell через `mcpProduct`. В реестре временных элементов остаётся напоминание обновить ссылку и проверить подлинные экраны перед выпуском серии.

## Редакционная проверка

Humanizer применён к заголовкам, введению, основному тексту, инструкциям, таблице, FAQ, подписям, CTA и SEO-метаданным. Убраны повторяющиеся описания подготовки и старые числа из отчёта Codex. Вместо общего совета добавлены действия по каждому наблюдаемому расхождению. В шаблоне запроса сохранили ID и технические значения, которые возвращает контракт чтения. Стадия и имя требуют сверки по CRM. Отпечаток записан в `humanizer-reviews.json`.

Независимое ревью охватило текущие отчёты продукта, источники, интент, текст и обе иллюстрации. Уточнили, что код стадии для сверки берут из справочника нужной воронки и что права на чтение определяются подключением. Живой тест ChatGPT с MCP TrueTell в этой работе не проводился.
