# SEO‑099 — отчёт по товарам в сделках Битрикс24

Дата проверки: 01.11.2026. Решение: CREATE, база знаний. Статус: локальный черновик `draft/noindex`, без публикации и поисковой индексации. Страница: `/otchet-po-tovaram-v-sdelkah-bitrix24/`. Интент — собрать сводку по отдельным товарам из многих сделок и сверить количество, число уникальных сделок и суммы строк. Это отличается от просмотра товаров одной сделки (`/tovary-v-sdelke-bitrix24/`), общего отчёта по продажам и страницы продукта.

## Факты и изображения

- Официальный Битрикс24: [наборы данных BI Конструктора](https://helpdesk.bitrix24.ru/open/22848752/) описывают `crm_deal_product_row`, `QUANTITY`, `SUM_TOTAL`, `DEAL_ID`, `CURRENCY_ID`, `STAGE_SEMANTIC_ID`; `CLOSEDATE`/`DEAL_CLOSEDATE` названы планируемой датой закрытия.
- [Готовые отчёты BI Конструктора](https://helpdesk.bitrix24.ru/open/19123608/) описывают товарную аналитику категорий и чеков, но не подтверждают количество каждого SKU и число уникальных сделок. Для этих показателей статья предлагает собственный отчёт по наборам данных или приложение TrueTell.
- [Прочие настройки CRM](https://helpdesk.bitrix24.ru/open/28033006/) подтверждают: при включённой настройке Битрикс24 обновляет «Дату завершения» при переходе в финальную стадию. Поэтому её нельзя без проверки назвать датой фактической продажи.
- Два подлинных скриншота текущего приложения TrueTell из `src/images/products/product-rating/`: `rating-products-2026-10-renamed.jpg` и `rating-deal-contribution-2026-10.png`. Данные синтетические, подписи их не выдают за результаты клиента. Оба снимка открываются в полном размере; мобильная верстка проверена при 390 px.
- Возможности приложения сверены по `/Users/ivan/projects/bitrix_product_rating/resources/js/analytics/domain.ts:83-95`, `ReportWorkspace.tsx:514`, `browserClient.ts:74-84`; фильтр использует REST `closedate` (`bitrix/deal.ts:51`). Клиентский портал и фактические оплаты не проверялись.
