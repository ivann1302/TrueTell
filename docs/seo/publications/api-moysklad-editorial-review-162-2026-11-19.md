## Факты и изображения

- Путь к токену сверили со [справкой МойСклад](https://support.moysklad.ru/hc/ru/касса%20и%20розница/онлайн%20кассы/интеграция_с_онлайн_кассами_aqsi). Подлинный снимок документации остался рядом с предупреждением об отзыве прежних токенов при вызове `POST /security/token`.
- Метод чтения, ограничение `limit=1` и структуру ответа сверили с [документацией товаров](https://github.com/moysklad/api-remap-1.2-doc/blob/master/md/dictionaries/_product.md#получить-список-товаров). Новая инфографика показывает учебный JSON с размером выборки и числом записей на странице.
- Обязательное сжатие, заголовки и ошибки сверили с [общими сведениями JSON API](https://github.com/moysklad/api-remap-1.2-doc/blob/master/md/_general.md). Команду выполнили в Bash и Zsh с подставной функцией curl и учебным токеном. Запрос с токеном клиента не проводился.
- Лимиты, их изменение с 1 декабря и вес двух методов сверили с [разделом ограничений](https://github.com/moysklad/api-remap-1.2-doc/blob/master/md/_restrictions.md). Параметр `moment` проверили по [документации отчёта об остатках](https://github.com/moysklad/api-remap-1.2-doc/blob/master/md/reports/_report_stock.md).

Независимый ревьюер сверил интент, первоисточники, текст, изображения и публичную версию до обновления. По замечаниям уточнили область действия метода, единицы паузы при 429, фильтр корзины, два метода отчёта с `moment` и ссылку на лимиты.
