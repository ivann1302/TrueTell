# Редакторская проверка версий для Дзена — 30.10.2026

Область: 12 опубликованных статей блога TrueTell, адаптированных для канала
https://dzen.ru/id/6aca2a4a8b4b8b72fe1a1b1a. Первоисточник — опубликованные
страницы https://truetell-retail.ru/ и локальная сборка сайта.

## Что изменено

Для каждой статьи переписаны заголовок, описание, три абзаца вступления, первый
абзац основного текста и начало двух тематических разделов. Конкретная рабочая
ситуация появляется раньше технического разбора. Числа, определения,
ограничения, инструкции, FAQ, источники, ссылки и подписи к изображениям
сохранены. Итоговая лента — `dzen.xml`; фрагменты для чтения — `preview.md`,
полные версии — `editor-html/`.

## Проверка

- Применён humanizer к новым заголовкам, описаниям и фрагментам: убраны
  расплывчатые обещания и преувеличения, сохранены факты и голос TrueTell.
- Независимый редакционный ревьюер сверил адаптированные начала разделов с
  исходниками. Ранние замечания к аудиту полей и статье о ДДС исправлены.
- В новой статье о доступе ИИ к CRM исправлен заголовок и вступление: проверка
  ответа по сделке больше не выдаётся за проверку прав доступа. Два исходных
  PNG шириной 600 px технически масштабированы до 800 px для требований RSS.
  Ревьюер подтвердил оба исправления.
- Финальный XML разобран парсером без ошибок: 12 `item`, 12 адаптаций,
  26 изображений допустимых форматов JPEG/PNG/GIF с соответствующим MIME.
  Подписи, ссылки, FAQ, `guid`, `link`, `category`, CTA и поддерживаемые HTML-теги
  проверены. Для двух новых статей отдельно сверены 17 ссылок, 15 FAQ,
  четыре изображения с подписями и четыре адаптированных раздела.
- `npm run build`, `npm run lint`, `node --test scripts/*.test.mjs` (88 тестов)
  и `node scripts/indexnow.mjs --check` завершились успешно. Сборка содержит
  побайтно ту же ленту и два новых PNG, что и `public/` сайта.

## Границы результата

Адаптация намеренно лёгкая. В основном корпусе остаются дословные фрагменты
сайта; проверка не доказывает, что Дзен признает статьи самостоятельными.
Даты исходных публикаций не изменялись: 12–29 октября 2026 года; только две
записи на 30 октября укладываются в рекомендованные Дзеном последние 2–3 дня.
Шесть публикаций имеют только календарную дату; в RSS для них технически стоит
00:00 Москвы. При отказе по содержанию повторная заявка, согласно справке
Дзена, возможна через шесть месяцев.

Скриншот Студии от 29.10.2026 подтверждает домен `truetell-retail.ru`.
Владелец сообщил 30.10.2026, что канал набрал 10 подписчиков. Доступность
кнопки после этого не проверена: управление браузером на URL Студии было
автоматически остановлено. На 30.10.2026 публичный адрес
`https://truetell-retail.ru/dzen.xml` возвращает HTTP 404. Лента добавлена
только локально в `public/` сайта: деплоя и подачи в Дзен не было. После
деплоя требуется проверить публичные XML и изображения, а результат
модерации Дзена заранее неизвестен.

## Обязательный шаг сборки — 30.10.2026

После этого отчёта генератор перенесён в проект TrueTell. В основном реестре
обнаружено 16 опубликованных статей блога: 12 имеют адаптации, четыре старые
статьи честно перечислены как переходные исключения в
`docs/seo/dzen/legacy-exclusions.json`. Пробная статья об аудите полей
назначена для ручного размещения; поэтому текущая сборка формирует 11 записей
RSS и 12 локальных редакторских копий с файлами изображений. Существующий
продуктовый CTA исходной статьи добавляется в обе версии.

`npm run build` и CI теперь останавливаются при отсутствии адаптации для
новой опубликованной статьи блога или непригодных изображениях. Прошли
`npm run lint` (три прежних предупреждения), `npm run build`,
`node --test scripts/*.test.mjs` (92 теста) и
`node scripts/indexnow.mjs --check`. Деплоя и подачи RSS по-прежнему не было.

## Первая подача через RSS — решение владельца 30.10.2026

Владелец выбрал подключение через RSS. Статья `audit-poley-crm-bitrix24/`
переведена из ручной подачи в RSS, поэтому ожидаемый состав первой ленты —
12 адаптированных статей. После сборки нужно проверить публичный XML и
изображения, затем владелец отправит адрес ленты на проверку в Студии Дзена.
Публикацию в Дзене до ответа платформы не считать завершённой.

После переключения заново прошли `npm run build` (12 RSS-записей),
`npm run lint` (0 ошибок, три прежних предупреждения),
`node --test scripts/*.test.mjs` (92/92) и
`node scripts/indexnow.mjs --check` (74 URL). Публичный `/dzen.xml` по-прежнему
отвечал HTTP 404 до релиза. Автоматическая проверка разрешений сначала
остановила коммит; затем владелец прямо разрешил коммит в `main` и общий
релиз сайта с PHP CRM. Подача RSS в Студии Дзена остаётся отдельным шагом
после проверки публичной ленты и изображений.
