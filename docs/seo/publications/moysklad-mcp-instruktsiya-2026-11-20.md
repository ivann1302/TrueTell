# Инструкция по подключению МойСклад MCP к ChatGPT или Claude

20.11.2026. Новый маршрут `/moysklad-mcp/instruktsiya/` отвечает на вопрос, как установить коннектор TrueTell, добавить его в ассистент и проверить первый ответ об остатках. Со страницы продукта есть ссылка в разделе `#connection`. Инструкция также доступна из базы знаний.

## Humanizer

Проверены введение, четыре шага, пример запроса, подписи, заголовки, тексты ссылок, поисковые метаданные и описание карточки. Порядок действий, четыре оригинала PNG, подписи, title и description сохранены из ZIP. Текст уточнён там, где изменился интерфейс или отсутствовало действие, необходимое для подключения. Редакционная проверка оставила точные названия элементов интерфейса и формулировку демонстрационного запроса.

## Фактологические источники

- Акт TrueTell о выпуске МойСклад MCP 3.2.10 от 19.11.2026 и HTML главного окна. Описана установка при доступной для аккаунта карточке и уточнены названия кнопки копирования и раздела управления доступом. Публичная установка не подтверждена.
- В ChatGPT добавлены обязательная отметка предупреждения и установка созданного плагина перед выбором в чате. Шаги сверены с [документацией OpenAI](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt).
- Для Claude указан путь добавления в личном аккаунте и путь администратора Team или Enterprise. [Справка Anthropic](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).
- Проверка количества опирается на показатель «Доступно» по каждому складу. [Справка МоегоСклада](https://support.moysklad.ru/hc/ru/товары_и_склады/остатки_и_себестоимость/отчет_остатки).

Предоставленные скриншоты показывают прежний интерфейс. Адрес подключения скрыт. Схема и диалог подписаны как схема и пример на демонстрационных данных. В рамках этой задачи подключение клиентского аккаунта не выполнялось.

## Независимое ревью

Отдельный ревьюер сверил материалы ZIP, справку OpenAI, Anthropic и МоегоСклада, код главного окна TrueTell 3.2.10 и акт выпуска. При повторной проверке подтверждены поправки по установке, актуальному интерфейсу и настройке обоих ассистентов. После ревью уточнена формулировка о доступе по ссылке и обновлён краткий шаг копирования на странице продукта. Исходные PNG побайтно совпадают с ZIP. Живая настройка в ChatGPT и Claude в рамках этой работы не проверялась.

## Локальная проверка

Прошли `npm run build`, 93 теста и `node scripts/indexnow.mjs --check`. Линтер завершился без ошибок, с тремя существующими предупреждениями в общих компонентах графика и слайдера.

В Chrome на ширинах 320, 390, 768 и 1440 px проверены якорь `#connection`, переход по ссылке с продукта, отсутствие горизонтальной прокрутки, загрузка всех WebP-превью и четыре подписи. Оригиналы PNG доступны по ссылкам в полный размер. У инструкции один H1, собственный canonical и запись в sitemap. Статус страницы: проверена локально.

## Уточнение про другие ИИ-ассистенты

По поручению владельца заголовок, поисковые метаданные и ссылка с продукта охватывают ChatGPT, Claude и другие ИИ-ассистенты. В шаге 3 выделен способ подключения для клиентов, принимающих адрес удалённого MCP-сервера по Streamable HTTP без отдельного OAuth. [Claude Code](https://code.claude.com/docs/en/mcp) и [Cursor](https://cursor.com/docs/mcp) приведены со ссылками на инструкции поставщиков. Транспорт сверён с инструкцией TrueTell 3.2.10. В этой редакции подключение к дополнительным клиентам в реальном аккаунте не проверялось.

Humanizer повторно применён к полному тексту, метаданным, ссылке с продукта и четырём подписям. Формулировка совместимости описывает проверяемые настройки клиента. Подписи и порядок шагов сохранены.

Независимый ревьюер подтвердил формулировки о совместимости, ссылки на официальную справку и путь с продукта. По замечанию ревьюера поисковое описание уточняет, что нужен удалённый MCP.
