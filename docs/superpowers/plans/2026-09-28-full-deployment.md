# Unified deployment implementation plan

User approved extending CI/CD to deploy Astro and Laravel together and asked for autonomous execution. Existing CRM spec remains binding.

Architecture: CI builds a production-only release archive. SSH with a pinned host key transfers it to a private releases directory. Each release contains public_html and backend; shared .env/storage are symlinked into backend. One current symlink selects the complete release. A one-time preparation command preserves the existing public_html and makes it point to current/public_html. Routine deployment never overwrites .env, regenerates APP_KEY, creates users, or deletes the database. Telegram stays disabled until configured.
