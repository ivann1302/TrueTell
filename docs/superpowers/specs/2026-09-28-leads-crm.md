# TrueTell: заявки и кабинет

Согласовано в диалоге: Astro остаётся статическим, PHP Laravel и MySQL работают на обычном SprintHost. Общая модальная форма: имя и сообщение необязательны, выбранный телефон/email/Telegram обязателен, отдельное согласие обязательно. Сохраняются источник, путь страницы, разрешённые UTM, версия согласия. Успех только после записи в БД. Защита от повторной отправки и ограничения частоты.

Все активные сотрудники видят все заявки и меняют статус new/processed. Администратор создаёт и отключает сотрудников. Личные пароли, обязательный TOTP, без регистрации; аудит статусов и отзыв сессий при отключении. Кабинет /workspace, не индексируется. Нестандартный путь не считается защитой.

UI соответствует одобренному изображению: таблица, поиск, фильтры, подробности справа; мобильная одна колонка. Светлая/тёмная тема сохраняется локально, изначально системная. Стили SCSS. Контакты компании только из src/config/company.ts.

Telegram изначально выключен. При включении новые заявки создают отдельную доставку каждому настроенному chat_id, только номер и ссылка. Повторы через cron, без постоянного worker. Исторические заявки автоматически не рассылаются. Ошибки бота не отменяют заявки.

Развёртывание отдельно от текущего FTP workflow: приватный backend вне document root, только public entrypoint доступен HTTP. Не публиковать реальные данные/секреты. Проверить тесты сайта, lint, build, IndexNow, PHP feature/security tests, static analysis, desktop/tablet/mobile UI и обе темы.
