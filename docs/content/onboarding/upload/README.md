# Слайды для загрузки

Загрузить четыре PNG по порядку 01–04. Размер каждого: 1536 × 1024. Архив marketplace-slides.zip содержит только эти четыре файла.

Внутри — настоящие скриншоты локального приложения с искусственными данными. Персонаж — иллюстрация. На втором слайде применено затемнение и выделена кнопка CSV. Исходники и HTML-макеты находятся в source. Реальная CRM не использовалась.
