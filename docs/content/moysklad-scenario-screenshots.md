# Скриншоты для страниц сценариев МойСклад

Пять новых страниц готовы для просмотра с заглушками. До проверки скриншотов они имеют `noindex, follow` и не добавлены в sitemap. Страница изменения цен остаётся индексируемой.

## Куда положить файлы

Все девять файлов сохранять в **`src/images/products/moysklad/`** с точными именами из таблицы. Формат — настоящий PNG; не переименовывать JPEG в PNG без конвертации. Общий компонент автоматически заменит заглушки после следующей сборки или перезапуска dev-сервера.

| Страница | Имя файла | Какой экран нужен | Место на странице |
| --- | --- | --- | --- |
| `/moysklad-udalenie/` | `delete-result.png` | Реальный отчёт удаления демонстрационных объектов: выполненные действия, ошибки/пропуски, оставшиеся объекты | «Проверьте, что удалено и что осталось» |
| `/moysklad-izmenenie-tovarov/` | `product-fields.png` | Форма изменения товаров: доступные поля, выбранные новые значения и демонстрационная выборка | Первый сценарий после краткого описания |
| `/moysklad-izmenenie-tovarov/` | `product-fields-plan.png` | Подготовленный план изменения полей с выбранными товарами и будущими значениями | Тёмный блок «Несколько полей в одной операции» |
| `/moysklad-arhivirovanie/` | `archive-selection.png` | Форма с действием «Архивирование», типом объектов и условиями выбора демонстрационных товаров | Первый сценарий |
| `/moysklad-arhivirovanie/` | `archive-result.png` | Реальный отчёт архивирования с результатами по демонстрационным карточкам | Тёмный блок «Одна операция для подготовленной группы» |
| `/moysklad-import/` | `import-plan.png` | План импорта подготовленного файла: будущие объекты и результаты проверки строк | Тёмный блок «Проверьте загрузку до подтверждения» |
| `/moysklad-import/` | `import-template.png` | Настоящий шаблон в табличном редакторе: заголовки колонок и 2–3 обезличенные строки | После таблицы поддерживаемых форматов |
| `/moysklad-izmenenie-dokumentov/` | `documents-action.png` | Форма выбора типа документа и действия; предпочтительно изменение статуса демонстрационных заказов | Первый сценарий |
| `/moysklad-izmenenie-dokumentov/` | `documents-result.png` | Реальный отчёт обработки той же группы документов с результатами по объектам | Тёмный блок «Выберите нужное действие» |

Уже используются существующие `delete-plan.jpeg` (удаление), `file-import.jpeg` (импорт), `prices.jpeg` и `price-plan.jpeg` (цены). `history.jpeg` показывает переоценку и не подставляется вместо отчётов других сценариев.

Снимайте интерфейс без панели браузера, желательно шириной 1280–1600 px. Используйте демонстрационные или обезличенные данные. Не создавайте ошибки специально в рабочих данных ради иллюстрации: если операция завершилась успешно, показывайте фактический успешный результат и нулевое количество ошибок. Подписи должны соответствовать реальному кадру.

## Что сделать после добавления

1. Проверить кадры и подписи. Сверить перечень полей товаров и доступные действия с документами с текущим приложением; неподтверждённые возможности не добавлять.
2. Пересобрать сайт и проверить, что в каждой готовой странице исчезли все заглушки. Путь и имя в пропсе `filename` компонента `Screenshot` должны совпадать с файлом.
3. В соответствующем `src/pages/moysklad-<сценарий>/index.astro` убрать `draft` у `ScenarioPage`. Для страницы без OG-изображения добавить импорт её первого реального кадра и передать `ogImage` / `ogImageAlt` по примеру страницы удаления.
4. Добавить готовый адрес в `src/pages/sitemap.xml.ts` по образцу `moysklad-izmenenie-cen/`.
5. Добавить контекстную ссылку с основной страницы приложения и связи из исходного документа:
   - цены → импорт, изменение товаров;
   - удаление → архивирование, изменение документов;
   - товары → цены, архивирование;
   - архивирование → товары, удаление;
   - импорт → цены, документы;
   - документы → импорт, удаление.
   Ссылки между черновиками пока не добавлены. Связи с уже готовой страницей цен и основной страницей работают.
6. Выполнить `npm run build`, `node --test scripts/*.test.mjs`, `npm run lint`, `node scripts/indexnow.mjs --check`; просмотреть mobile и desktop перед публикацией.

Деплой в рамках подготовки этих страниц не выполнялся.
